Python · SHA-256 · File inventory · JSON

Forensic File Integrity

File-inventory utility prototype for technical analysis. It inventories a selected evidence copy, recording file paths, sizes, UTC modification timestamps and SHA-256 hashes. Symbolic links are excluded.

Source codeDocumentation
01 / INVENTORY

File metadata

Collects path, size and filesystem modification time for readable, non-linked files.

02 / INTEGRITY

SHA-256

Calculates a digest that can be compared against a trusted reference value.

03 / OUTPUT

JSON report

Structured output is written to stdout, with per-file read errors recorded.
